서문

이 책은 한국 정치학 석사과정생을 주 독자로 삼아, 검증 가능한 방식으로 AI를 연구 워크플로에 들이는 법을 다룬다. 특정 챗봇의 팁 모음이 아니라, Git·CLI 에이전트·스킬·하니스·문헌 파이프라인·텍스트 어노테이션으로 이어지는 재현가능한 구조를 한 줄기로 익히게 하는 것이 목적이다.

이 판의 범위

지금 읽고 있는 것은 원래 구상했던 13장+부록 전체본이 아니라, 이미 초고가 있는 장으로 묶은 핵심편이다. 다루는 것은 다음이다.

  • 연구 산출물을 추적 가능하게 만드는 바닥(1~2장)
  • 반복 절차를 모듈화하고, 위임 단위를 정하고, 검증 구조로 감싸는 법(3~5장)
  • 문헌 작업과 텍스트 코딩에 그 구조를 적용한 실전(6~7장)
  • 앞 장들의 검증·공개 논지를 한곳에 모은 종장(8장)

다루지 않는 것 — 더 정확히, 이 판의 본문에 아직 없는 것 — 도 밝힌다. 시각 데이터, OCR·스캔 문서, 서베이·silicon sampling, AI 인터뷰어는 원래 목차에 있었으나 집필 전이므로 종장에서 확장 주제로만 예고한다. 약속이 아니라 로드맵이다.

실습 코드

책 본문의 코드는 발췌다. 실행 가능한 전문, 연습 데이터, 설치 안내는 공개 저장소에 둔다.

  • 실습 저장소: https://github.com/woochangkang/ai-socsci-code
  • 장 번호: 책의 N장 ↔︎ 저장소의 ch0N-…/ 폴더 (README의 지도 표 참조)
  • 유료 API가 필요한 실습은 폴더 README에 비용·대안(로컬/모의)을 적었다

저장소 샘플 데이터는 학습용이다. 7장 본문이 인용하는 의안 젠더 분류의 실측 수치와 저장소 연습 표본을 같은 숫자로 읽지 말라.

이 책의 AI 사용 공개 진술

이 원고 자체도 이 책이 가르치는 방식으로 쓰였다. 요약하면 다음과 같다.

  • 도구: Claude Code 등 CLI 에이전트, 간헐적으로 다른 계열 CLI(교차 검토), Quarto, Git.
  • 용도: 초고 작성 보조, 구조·문장 개정 제안, 실물 세션 캡처, 코드·그림 스크립트 작성, 교차 감사. 장 단위 논지·사례 선택·사실 확인·최종 문장 책임은 저자에게 있다.
  • 하지 않은 것: 저자 없는 자동 생성 원고의 그대로 수록, 검증 없는 수치 삽입, 원문 미대조 인용.
  • 기록: 장별 개정과 캡처 원본은 Git 이력과 실습 저장소(공개 가능한 범위)에 남긴다.

더 긴 형식의 공개 진술 예시는 8장과 실습 저장소 templates/ai-disclosure-ko.md에 있다.
