# 회차 비교 파일 (3.3.1의 5단계)

같은 요청을 에이전트에 세 번 넣어 표가 같은지 확인한 기록이다. 각 회차의 응답에서
**표 행만** 뽑아 저장했다 — 서술 문장은 회차마다 다르고, 대조 대상은 표이기 때문이다.

추출 방법은 이렇다.

```bash
claude -p "data-raw에 설문 자료 들어왔는데 변수별로 정리 좀 해줘" | grep -E "^\| " > run1.txt
```

`grep`이 `| `로 시작하는 줄만 남기므로 구분선(`|---|---|`)과 "제외한 열" 안내는
빠진다. 그래서 이 파일들의 체크섬은 `describe.R`의 **원출력** 체크섬과 다르다.
같은 추출을 원출력에 적용하면 일치한다.

```bash
Rscript ../scripts/describe.R ../../ch01/practice_survey.csv | grep -E "^\| " | md5
# b96ab80f76f763e98cdf5074622a5c04  ← run1.txt · run2.txt 와 같은 값
```

본문 3.3.1의 5단계에 실린 md5가 이 값이다.
