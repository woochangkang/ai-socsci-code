# voter2026.csv 변수 사전

2장 2.4.1의 CLAUDE.md 예시가 "먼저 읽을 것"이라고 지시하는 `docs/codebook.md`가
이 파일이다. 실습 프로젝트에서는 `docs/` 아래에 둔다.

| 변수 | 라벨 | 값 | 비고 |
|---|---|---|---|
| `id` | 응답자 번호 | 1–500 | 통계에 쓰지 않는다 |
| `gender` | 성별 | 남성 / 여성 | |
| `age` | 만 연령 | 19–79 | |
| `region` | 거주 지역 | 서울 / 경기·인천 / 충청 / 호남 / 영남 / 강원·제주 | 결측은 문자 `"무응답"` |
| `ideology` | 주관적 이념 | 0–10 | **결측 `-9`.** 방향(0이 진보인지)은 확정하지 않았다 |
| `q1` | 정치신뢰 문항 1 | 1–5 | 결측 `-9` |
| `q2` | 정치신뢰 문항 2 | 1–5 | 결측 `-9` |
| `q3` | 정치신뢰 문항 3 | 1–5 | **역코딩 문항.** 결측 `-9` |
| `wt` | 가중치 | 0.4–2.1 | 비정규화(합 ≠ n) |

실재 조사가 아니라 난수로 만든 합성 자료다. 생성 방법은 `make_voter2026.py`.
