# CSV Descriptives — 변수별 기술통계표

본 skill은 CSV 파일을 입력받아 수치형 변수별 **n, mean, sd, min, max** 기술통계표를 생성한다. 계산 로직은 `scripts/descriptives.R`에 고정되어 있으며, **어떤 경우에도 즉석에서 통계를 계산하거나 새 코드를 작성하지 않는다** — 항상 이 스크립트를 실행하고 그 출력을 그대로 사용한다. 재현성(같은 CSV → 같은 표)이 이 스킬의 존재 이유다.

## 활성화 조건 (When to use)
- ✅ 사용자가 CSV를 주며 기술통계·요약통계·변수별 평균 등을 요청할 때
- ✅ "이 데이터 변수별로 n/평균/표준편차 표로 만들어줘"류 요청
- ✅ `/csv-descriptives <파일경로>` 명시 호출
- ❌ 빈도표·분포·신뢰도 등 본격 초벌분석 → `survey-prelim-analysis` 스킬 사용
- ❌ 회귀·검정 등 추론 통계 요청 (본 스킬 범위 아님)

## 실행 절차 (고정)

1. 입력 CSV의 절대 경로 확인 (없으면 사용자에게 요청)
2. 다음 명령을 실행한다 (`<skill-dir>`은 본 SKILL.md가 있는 폴더):

   ```bash
   Rscript <skill-dir>/scripts/descriptives.R <input.csv>
   ```

3. stdout의 마크다운 표를 **그대로** 사용자에게 보여준다 (숫자 재계산·재포맷 금지)
4. "제외된 비수치형 변수" 줄이 있으면 함께 전달
5. 사용자가 파일 저장을 원하면 `--out=<경로>.csv` 옵션으로 재실행

## 스크립트 인터페이스

| 인자/옵션 | 기본값 | 설명 |
|---|---|---|
| `<input.csv>` | (필수) | 입력 CSV 절대 경로 |
| `--out=PATH` | 저장 안 함 | 결과 표를 CSV로 저장 |
| `--digits=N` | 2 | 소수점 자릿수 |
| `--encoding=ENC` | UTF-8 | 한글 깨짐·"수치형 변수 없음" 오류 시 `CP949` 시도 |

- 의존성: base R만 사용 (패키지 설치 불필요)
- n은 변수별 **비결측 관측치 수** (전체 행 수 아님)
- 문자형·factor 변수는 표에서 제외되고 하단에 목록으로 보고됨

## 알려진 한계·flag

- 수치형 변수만 집계한다. 숫자가 문자로 읽히면(예: `"1,234"` 천단위 콤마) 제외 목록에 뜨므로, 그 경우 원인을 사용자에게 보고할 것 (스크립트를 고치지 말 것)
- id류 식별자 열도 수치형이면 표에 포함된다 — 필요 시 사용자가 해석에서 제외
- 스크립트 수정은 사용자 승인 없이는 금지. 수정 시 이 표의 사양도 함께 갱신할 것
